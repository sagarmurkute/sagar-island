# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Sagar Island, please **do not open a public issue**. 

Instead, report it privately to the maintainer via email at **contactsagar.design@gmail.com** or through GitHub Security Advisories.

Please include:
1. Description of the vulnerability.
2. Steps or proof-of-concept to reproduce the issue.
3. Affected versions and operating system environment.

We will acknowledge receipt of your report within 48 hours and work on a prompt patch.
